# celobus-descriptor

The [Celobus](https://celobus.com) plugin descriptor, what a plugin prints for `--describe`: its schema, its
canonical JSON, its validation (every problem as an `E_*` code with a path) and the manifest derived from it. Part of
[`celobus-sdk`](https://crates.io/crates/celobus-sdk).
