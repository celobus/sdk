# celobus-sdk-derive

The derive macros of the [Celobus](https://celobus.com) plugin SDK, `Message` and `Entity`. Use them through
[`celobus-sdk`](https://crates.io/crates/celobus-sdk) (`use celobus_sdk::prelude::*;`), not on their own.
